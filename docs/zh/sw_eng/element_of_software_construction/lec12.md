## 介绍

阅读内容介绍了几个概念：

- 语法，包括生成式（productions）、非终结符、终结符和运算符
- 正则表达式
- 解析器生成器

一些程序模块以字节序列或字符序列的形式接收输入或产生输出，当它只是存储在内存中时，被称为字符串；当它流入或流出模块时，被称为流。与我们一直在开发的具有多个客户端和实现的方法非常相似，许多不同的用户对这些字符串或流的格式有着共同的理解；换句话说，这些序列需要一份规范。在今天的阅读内容中，我们将讨论如何为这样的序列编写一份规范。具体来说，字节或字符序列可能是：

- 一个字符串
- 磁盘的一个文件，这种情况下，规范称为文件格式
- 通过网络发送的消息，这种情况下，规范称为有线协议（wire protocol）
- 用户在控制台上输入的命令，这种情况下，规范称为命令行界面。

对于这些类型的序列，我们引入了语法的概念，它不仅使我们能够区分合法和非法序列，还能将序列解析为程序可以使用的数据结构。语法生成的数据结构通常是**递归数据类型**。

我们还讨论了语法的一种特殊形式，称为正则表达式。除了用于规范和解析之外，正则表达式还是许多字符串处理任务的广泛使用工具，这些任务需要反汇编字符串、从中提取信息或对其进行转换。 最后，我们将讨论解析器生成器，它是一种将语法自动转换为该语法的解析器的工具。
