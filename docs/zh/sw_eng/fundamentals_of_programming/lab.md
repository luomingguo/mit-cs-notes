# Lab 0 音频处理

## 实验简介

在物理学中，当我们谈论声音时，我们指的是空气压力的波。当声音产生时，由相对高压区（“压缩”）和相对低压区（“稀疏”）交替形成的声波在空气中传播。

当我们使用麦克风以数字方式捕捉声音时，我们通过对与空气压力成比例的电信号进行周期性测量来实现这一点。每个单独的测量值（通常称为“样本”）对应于某一时刻的空气压力；通过以恒定的速率（“采样率”，通常以每秒捕获的样本数来衡量）重复进行测量，这些测量值共同形成了声音的表示，通过近似空气压力随时间的变化。

当扬声器回放声音时，它通过将这些测量值转换回交替的空气压力波（通过使膜片按这些捕获的测量值成比例地移动）来实现。为了忠实地表示声音，我们需要知道两个方面：采样率和实际捕获的样本。

对于以单声道录制的声音，每个样本是一个正数或负数，对应于某一时刻的空气压力。对于以立体声录制的声音，每个样本可以看作由两个值组成：一个用于左扬声器，另一个用于右扬声器。

### 混合音频

接下来，我们将研究将两个声音混合在一起以创建新声音的效果。我们将这种行为实现为一个名为 `mix` 的函数。`mix` 应该接受三个输入：

1. 两个声音（使用字典表示）
2. 一个“混合参数”（一个浮点数，0 到 1 之间）

`mix` 函数应该按照以下步骤操作：

1. **混合参数**：`mix` 函数将音频样本的比例加权结合。具体地，它应该将第一个声音的样本乘以混合参数 `α`（0 到 1 之间），将第二个声音的样本乘以 `1 - α`，然后将它们相加，以生成新的声音。
2. **采样率**：两个输入声音应具有相同的采样率。如果提供的声音具有不同的采样率，函数应该返回 `None`，而不是返回声音。
3. **处理长度**：尽管输入声音具有相同的采样率，但它们可能有不同的持续时间。结果声音的长度应为两个输入声音的最大长度，以确保可以完整地听到两个声音（如果其中一个声音在中间被截断，会显得很突兀）。

这种方式很好地实现了卷积（如果你愿意，你可以这样做），但也许考虑卷积的另一种稍微不同的方式会更容易。我们的卷积核由一组值表示。对于卷积核中的每一个非零值，我们创建输入声音样本的副本，这些副本按 iii 偏移并按 hih_ihi 缩放；将这些新的信号列表相加得到我们的输出。输出的总长度应为输入声音样本长度加上卷积核样本长度再减去一。

```python

  'samples': [3, 0, -2, 1, 0, 4]
}

```

在计算 `convolve(s, kernel)` 的结果时，我们知道输出最终会有 9 个样本（即样本长度加上卷积核长度再减去 1）。

- 核心中索引 0 的 2 对我们的输出贡献了像原始样本按 2 缩放并偏移 0 的值：`[6, 0, -4, 2, 0, 8, 0, 0, 0]`。
- 核心中索引 1 的 5 对我们的输出贡献了像原始样本按 5 缩放并偏移 1 的值：`[0, 15, 0, -10, 5, 0, 20, 0, 0]`。
- 核心中索引 2 的 0 对我们的输出没有贡献。
- 核心中索引 3 的 4 对我们的输出贡献了像原始样本按 4 缩放并偏移 3 的值：`[0, 0, 0, 12, 0, -8, 4, 0, 16]`。

将这些列表中对应的元素相加，我们得到的总体结果是：`[6, 15, -4, 4, 5, 0, 24, 0, 16]`。这些代表了我们输出声音的样本（其采样率应与输入相同）。

### 回声

接下来，我们将实现一个经典的效果：回声滤波器。我们通过从原始声音开始，并添加一个或多个额外的声音副本，每个副本都被延迟了一段时间，并且缩小了声音的强度，从而模拟回声效果。

我们将实现这个滤波器为一个名为 `echo` 的函数。该函数应接受以下参数：

- `sound`: 一个表示原始声音的字典
- `num_echoes`: 要添加的额外声音副本的数量
- `delay`: 每个“回声”应该延迟的时间（以秒为单位）
- `scale`: 每个回声样本应该缩放的量

一个好的开始是确定每个副本应该延迟多少个样本。为了确保你的结果与我们的检查器一致，你应该使用 Python 的 `round` 函数：`sample_delay = round(delay * sound['rate'])`。

我们应该添加一个延迟和缩小的声音副本（按给定的缩放值缩放并偏移 `sample_delay` 样本）。注意，每个新的副本应该比前一个副本缩小更多（第一个副本乘以 `scale`，第二个副本乘以 `scale**2`，第三个副本乘以 `scale**3`，依此类推）。

总的来说，为了避免剪切掉任何回声，输出的长度应该比输入长度多出 `num_echoes * sample_delay` 个样本。

- 左声道的第一个样本缩放因子是 `1`，第二个是 `n-2/(n-1)`，第三个是 `n-3/(n-1)`，依此类推，最后一个样本的缩放因子是 `0`。

## 3 通过卷积图像滤镜处理

接下来，我们将探索一些稍微复杂的图像处理技术，其中涉及到一个叫做相关性（correlation）的操作。

给定一个输入图像``I``和一个卷积核``k``，将``k``应用于``I``会生成一个新的图像``O``（可能具有非整数或超出范围的像素值），其高度和宽度与``I``相等。输出图像的像素值按照卷积核``k``所描述的规则进行计算。

应用``k``到``I``的过程被称为相关性：输出图像中某一位置``(r,c)``像素的**亮度**（我们将其表示为$O_{r, c}$， 最左下角的记为$O_{0,0}$），是输入图像中位置``（r, c）``附近像素亮度的线性组合，其中权重由卷积核``k``提供。

例如，考虑一个卷积核：

![image_convolution](https://tc-1258979383.cos.ap-guangzhou.myqcloud.com/66c6be5dacdc0.png)

当我们将这个卷积核应用于图像时，每个输出像素的亮度是输入图像中距离该位置最近的9个像素亮度的线性组合，每个输入像素的值都乘以卷积核中相应的值：

![image_convolution](https://tc-1258979383.cos.ap-guangzhou.myqcloud.com/66c6be88574a6.png)
$$
\begin{aligned} O_{r,c} = & I_{r-1, c-1} \times k_{0,0} + I_{r-1,c} \times k_{0,1} + I_{r-1,c+1} \times k_{0, 2} +\\ & I_{r, c-1} \times k_{1,0} + I_{r,c} \times k_{1,1} + I_{r,c+1} \times k_{1, 2} +\\ & I_{r+1, c-1} \times k_{2,0} + I_{r+1,c} \times k_{2,1} + I_{r+1,c+1} \times k_{2, 2} \end{aligned}
$$

### 边缘效应

在计算图像边缘的像素时，可用的输入像素少于9个。例如，考虑位置在左上角的像素。在这种情况下，所有位于像素上方和左侧的像素都是越界的。我们有几种选项来处理这些边缘效应：

- zero：一种方法是将每个越界像素的值视为0。
- extend：另一种方法是扩展输入图像的边界，这将在下一段解释。 
- wrap：另一种方法是对图像的边缘进行包裹处理，这将在之后的段落中解释。

如果我们希望通过图像的扩展版本(extend)来考虑这些越界像素，图像左侧的值应视为图像第0列的值，图像上方的值应视为图像第0行的值，等等。下图中间的粗体像素代表原始图像，而该区域外的像素代表“扩展”版本的逻辑值（虽然下图中只显示了有限数量的像素，但这个过程在所有方向上无限延续）：

### 锐化

接下来，我们将实现相反的操作，称为锐化滤波器。这个“锐化”操作通常以另一个更能说明其含义的名称出现：它通常被称为反锐化掩模（unsharp mask），因为它的结果是通过从图像的一个缩放版本中减去该图像的一个“反锐化”（模糊）版本得到的。

更具体地说，如果我们有一张图像（`I`）和同一图像的一个模糊版本（`B`），则锐化图像`S`在特定位置的值为：

$S(i, j) = 2 * I(i, j) - B(i, j)$

我们可以通过计算图像的模糊版本，然后对每个像素，根据上面的公式计算其值来实现此操作。

```python
def greyscale_image_from_color_image(image):

        for i in range(0, len(image['pixels']), 3)

    }

```
