# 学习路径

目录树只能告诉你「有哪些课」，回答不了「我想搞懂数据库内核，该按什么顺序读」。

这里把全站笔记按**目标**重新组织：选一个你想到达的地方，下面会给出一条跨课程的路线 —— 每一步为什么排在这个位置、该读哪几篇、以及怎么自测有没有真的过关。
