## 什么是计算机架构

计算机架构关注的是**软硬件之间的接口与分层**：从晶体管、门电路、组合/时序逻辑出发，逐层向上构建出指令集架构（ISA）、微架构（处理器、流水线、缓存、虚拟内存），再到操作系统与并行/专用硬件，最终承载起上层软件。每一层都向上提供一个抽象，向下隐藏实现细节——这正是"架构"二字的核心：

- **抽象与分层**：指令集（ISA）是软件与硬件之间最关键的接口，编译器只需面向ISA编程，处理器只需正确实现ISA语义
- **底层实现**：组合/时序电路 → 数据通路 → 流水线处理器 → 缓存与存储层次
- **权衡设计**：延迟、吞吐量、面积、功耗之间的取舍，贯穿从通用处理器到专用加速器的设计
