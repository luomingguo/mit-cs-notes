## 课程描述

它旨在帮助学生建立对内存和相关主题的理解，包括指针、不同数据结构在内存中的存储方式、堆栈和堆，以便对现代计算系统中操作复杂数据结构的限制有一个深入的理解。此外，该课程还研究汇编语言，以便让学生深入了解高级语言是如何被翻译成机器级指令的。

*J. Steinmeyer*
