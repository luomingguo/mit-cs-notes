# 论文阅读： Virtual Memory Primitives for User Programs

## 概要

内存管理单元（MMUs）传统上被操作系统用于实现基于磁盘的分页虚拟内存。一些操作系统允许用户程序指定页面的保护级别（不可访问、只读、读写），并允许用户程序处理保护违规，但这些机制并不总是健壮、高效，或与应用程序的需求相匹配。
我们对几种使用页面保护技术的用户级算法进行了调查，并分析了它们的共同特征，试图回答以下问题：“操作系统应该为用户进程提供哪些虚拟内存原语？当前的操作系统在多大程度上能够提供这些原语？”
