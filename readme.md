# About Project

MIT EECS Open Course Learning Notes — a personal collection of notes, code examples, and exercises from MIT open courses, covering computer systems, theoretical computer science, computer security, computer architecture, and software engineering.

# 关于项目

MIT EECS 公开课学习笔记，整理自 MIT EECS 公开课程的个人笔记、代码示例和习题，内容涵盖计算机系统、理论计算机、计算机安全、计算机架构以及软件工程等方面。
