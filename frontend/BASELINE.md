# Astro 迁移与视觉验收基线

本目录是独立 Astro 前端。它只读取 `../docs/**/*.md`，不修改 Markdown 源文件，也不依赖 VitePress 的 Layout、DOM 或 CSS。

## 已实现范围

- 工作流：视觉重构 + 完整 Astro 路由迁移 + 只读内容数据派生 + 双部署目标切换准备。
- 样本：构建时按可重复规则从中文讲义中自动选择；候选必须同时含公式、代码、表格、图片、语义容器，按覆盖项、标题数、正文长度排序。
- 页面：主页、领域页、课程页和全部中文 Markdown 路由；导航、上一篇/下一篇、搜索、目录与元数据均从 Markdown、目录结构和 Git 历史派生。
- 保留契约：数学公式、代码高亮、表格、图片、语义容器、标题锚点、深浅色、双语入口、RAG、根路径与 GitHub Pages 子路径。
- 不在范围：账户、跨设备访客阅读进度、全局知识图谱和在线编辑。缺少结构化关系数据的模块显示诚实空状态。

## 1440px 页面结构

| 区域 | 基线 | 实现约束 |
| --- | --- | --- |
| 左栏 | 约 292px | `292px`，视口高 sticky；品牌、主题、搜索、领域/课程树 |
| 中栏 | 正文约 720px | 弹性列，正文 `max-width: 720px`，两侧留白约 44px |
| 右栏 | 约 276px | `276px`，视口高 sticky；页内目录、课程收录、关系空状态 |
| 页面顶部 | 无桌面全局顶栏 | 品牌与入口归入左栏；正文从约 40px 开始 |

## 信息顺序

1. 左栏品牌与主题入口、Command Palette 搜索、分层课程导航。
2. 正文面包屑、长标题、真实元数据、正文摘要。
3. 关系版位：只展示能从目录和 Markdown 推导的同课程前后篇；无可靠数据的前置关系不伪造。
4. Markdown 正文：标题、公式、代码、表格、图片、语义容器、锚点。
5. 上一篇/下一篇。
6. 右栏页内目录、课程收录信息、相关概念/反向链接的诚实空状态或真实派生结果。
7. 页面级“问我的笔记”入口沿用旧站同源 `/rag/ask` SSE 契约；静态预览不伪造回答。

## 视觉令牌

- 亮色：白色正文、`#fbfbfa` 左栏、`#17171a` 正文、`#74746e` 次要文字、`#e6e6e2` 边界、`#1f5fa8` 强调色。
- 暗色：`#121215` 正文、`#16161a` 左栏、`#ececeb` 正文、`#8f8f89` 次要文字、`#27272d` 边界、`#79b0e8` 强调色。
- 标题与正文：Source Serif 4 + Noto Serif SC 回退；界面：系统中文无衬线；路径与元信息：JetBrains Mono。
- 克制的 6–8px 圆角与 1px 边界；不使用渐变、发光、层叠卡片或正文入场动画。

## 交互与响应式

- `Cmd/Ctrl + K` 打开搜索，支持领域/课程/讲义类型筛选、上下键、Enter、Esc；结果来自完整真实中文语料。
- “问我的笔记”以可访问对话框承接旧站 RAG 入口，流式展示回答与真实引用来源；后端缺席时明确报错。
- 目录用 IntersectionObserver 反映当前章节。
- 主题在首帧前读取本地偏好，避免闪烁；交互只增强，正文无脚本仍可读。
- `>= 1280px`：三栏；`768–1279px`：左栏 + 正文，右栏改为抽屉；`< 768px`：顶部工具栏 + 正文，左右栏均为抽屉。
- 所有宽度禁止页面级横向滚动；代码、表格和公式在自身容器内横向滚动。
- 所有控件使用语义元素、可见焦点，并尊重 `prefers-reduced-motion`。

## 数据规则

- “课程收录”只表示仓库中该课程目录下可读取的讲义数量，不表示访客阅读进度。
- “相关概念”只取当前 Markdown frontmatter 的真实 tags；空数组显示空状态。
- “反向链接”从完整中文 Markdown 语料中的内部链接反向计算；没有结果显示空状态。
- Git 最后修改时间仅在 Git 能提供历史时展示；不以构建时间冒充更新时间。
